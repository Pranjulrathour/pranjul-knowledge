# pranjul-knowledge

Public knowledge and media library behind [pranjulrathour.scult.in](https://pranjulrathour.scult.in).

- `knowledge/` — exported knowledge (facts, writing, research metadata) the site's control room builds its knowledge base from
- `media/` — photos, project covers and PDFs that already appear on the site, served via GitHub raw or jsDelivr
- `media/manifest.json` — every file with size, hash, dimensions and both URLs

Text and metadata live in the site's database; files live here, so the database stores no binaries.
